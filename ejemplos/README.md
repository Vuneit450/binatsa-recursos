## Reglas
- El repositorio es PÚBLICO: ninguna captura puede mostrar nombres de clientes, cifras reales de cobranza, identificadores de asesores ni credenciales. Usar datos de ejemplo o difuminar.
- Recortar al elemento que se ilustra; nada alrededor.
- Peso máximo de 1 MB por imagen.
- Cada módulo que use una imagen la enlaza junto a la regla y deja la descripción en texto al lado, para que sirva aunque quien lee no pueda ver imágenes.
