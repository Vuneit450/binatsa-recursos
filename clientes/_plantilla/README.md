# Plantilla de cliente

1. Copiar esta carpeta como `clientes/<cliente>/`.
2. Agregar `logo.svg` (o `logo.png`).
3. Crear `paleta.md` con el formato de `logos/paleta-binatsa.md`: primario, secundario, tono oscuro del primario, neutros, rampa de segmentos (todos los pasos a 3:1 o más contra blanco) y tabla de contraste.
4. Borrar este archivo.
