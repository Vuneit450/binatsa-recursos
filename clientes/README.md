# Clientes

Una carpeta por cliente, con su logo y sus recursos de marca individuales. Los skills de dashboards la consultan en el paso "Logo del cliente" y "Colores de marca".

```
clientes/
  _plantilla/          copiar y renombrar para un cliente nuevo
  <cliente>/
    logo.svg           (o logo.png si no hay vectorial)
    paleta.md          mismo formato que logos/paleta-binatsa.md
```

## Reglas

- Nombre de carpeta en minúsculas y con guiones, por ejemplo `nombre-del-cliente`.
- Este repositorio es PÚBLICO, así que el nombre de cada carpeta es visible para cualquiera. Subir solo lo que el cliente ya usa públicamente: su logo y sus colores de marca. Nunca contratos, datos de cobranza, accesos ni nada interno.
- Antes de subir el logo o la paleta de un cliente, confirmarlo con el usuario.
- Cada paleta debe revisar el contraste (texto blanco sobre las franjas: mínimo 4.5:1; barras, líneas y números: mínimo 3:1) y, si el color principal no llega, documentar su tono oscuro.
